# @reeris/core

Reeris UI Core: native-web CSS, tokens, layouts, forms, components and utilities. Core has zero production dependencies and requires no JavaScript.

See the root Reeris UI README and documentation for component contracts, theming, accessibility and browser-support policy.

## Source maps

The package ships `reeris.css.map` and `reeris.min.css.map` plus their mapped CSS modules under `dist/sources/`, so browser DevTools can trace compiled rules back to individual Reeris source files.
