# Reeris UI official starters

These pages are integration references for Reeris Core 0.40. They deliberately use the public Reeris stylesheet without a starter-specific CSS file.

- `dashboard.html` — application shell + dashboard
- `data-management.html` — application shell + structured data workflow
- `authentication.html` — account-entry composition
- `settings.html` — settings/preferences composition
- `marketing.html` — responsive marketing/landing composition

The starter integration audit rejects unknown CSS classes, inline event handlers, embedded `<style>` blocks, non-Reeris custom-property overrides, missing landmark/head metadata, and missing expected composition anchors.
