# Pre-Reeris historical evidence

This directory preserves supplemental local-browser evidence collected under the earlier **Reva UI** development identity for versions 0.49.0 and 0.50.0.

These records are intentionally outside the active Reeris UI Release Lab evidence ledger because the 0.51 ecosystem rename changed public package names, data attributes, CSS token prefixes and generated artifacts. Historical evidence remains available for traceability but cannot close Reeris UI release criteria.
