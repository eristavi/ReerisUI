# Reeris UI repository and documentation location decision

Date: 2026-09-29 (Asia/Nicosia)
Project owner: Revaz Eristavi
Evidence reviewer: Codex

The canonical source repository is `https://github.com/Eristavi/ReerisUI`. The repository is public, owned by the signed-in `eristavi` account, and uses `main` as its default branch. The GitHub repository connector reports administrator permission for that account. The project owner has explicitly confirmed that **Reeris UI** is the intended name.

The current canonical documentation is `https://eristavi.github.io/ReerisUI/docs/index.html`; README links to that location and its API and starter pages. Keep this GitHub Pages location for the 0.55 release. The owner has chosen a future subdomain under `eristavi.org` but explicitly directed us not to configure or register a new domain yet. No `reeris.*` domain is required for this release, and no redirect or DNS change is authorized now.

This decision closes only the repository/domain-location criterion. It does not decide trademark similarity or prove control of the `@reeris` npm scope. Those criteria remain open, and package publication remains blocked.

Sources checked: GitHub repository metadata for `Eristavi/ReerisUI` on 2026-09-29, deployed GitHub Pages documentation, current README links, and the owner's naming/domain instructions in this conversation.
