CSS carousels

Swipe, scroll, or focus the track and use the arrow keys. Browsers with CSS carousel controls also show previous/next buttons; the single-slide layout adds named slide markers. No script runs on this page.

Responsive card rail

Three cards fit in a wide container, two at medium widths, and one on a phone. The list stays scrollable even when generated controls are unavailable.

Use it with your content

The track can hold cards, figures, images, or videos. Keep video playback under user control; the carousel does not autoplay or loop. Give each carousel an accessible name, add tabindex="0" to the track for keyboard scrolling, and label slides when using markers.

<div class="carousel single" role="region" aria-roledescription="carousel" aria-label="Project gallery">
  <ul class="carousel-track" tabindex="0" aria-label="Project gallery, scroll horizontally">
    <li class="carousel-slide" data-label="Project photograph">
      <img src="photo.jpg" alt="Exterior of the project">
    </li>
    <li class="carousel-slide" data-label="Project video">
      <video controls preload="none" poster="video-poster.jpg">
        <source src="tour.mp4" type="video/mp4">
      </video>
    </li>
  </ul>
</div>

Generated buttons and markers depend on CSS Overflow 5 support. In other browsers, the native scrollbar, swipe, trackpad, and focused track remain available. This version deliberately has no automatic playback or infinite wrap.
