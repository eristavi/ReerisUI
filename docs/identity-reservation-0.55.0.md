Reeris UI is the selected pre-1.0 identity. The canonical repository is [`Eristavi/ReerisUI`](https://github.com/Eristavi/ReerisUI), and the intended npm ecosystem is `@reeris/*`. This is a fresh public-source check on 28 September 2026, not an account-level reservation or formal trademark review.

## GitHub identity

GitHub's repository API confirmed `Eristavi/ReerisUI` is public, owned by `eristavi`, with `main` as its default branch. The previous 0.52 report's 404 observation is historical and no longer describes the repository. The repository part of the identity target is verified; the combined repository/domain publication criterion remains open.

## Domain checks

The [Verisign RDAP service](https://rdap.verisign.com/com/v1/) returned 404 for `reeris.com` and `reerisui.com`. Requests to the `.dev` RDAP endpoint returned 502 in this environment, so no conclusion was drawn for `reeris.dev` or `reerisui.dev`. The remaining `reeris.io` and `reeris.org` candidates were not checked in this pass. A missing RDAP record is **not** a completed registrar transaction. **Do not treat any of these as available until a registrar confirms and completes registration.**

Preferred candidate order remains `reeris.dev`, `reerisui.dev`, `reeris.com`, `reerisui.com`, `reeris.io`, `reeris.org`.
