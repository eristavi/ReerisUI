A little depth, entirely in CSS.

The background moves gently as this section passes through the viewport. The content remains still and readable.

Use .parallax with a decorative .parallax-media and normal-flow .parallax-content. The default travel is 8%; add .subtle for 4% or .strong for 12%. Add .gentle for ease-in-out instead of linear travel. These options work together. For an exact value, set --reeris-parallax-travel on the section (keep it within 12% to avoid revealing the edges). The motion curve changes the scroll-to-position mapping; it does not introduce delayed tracking.

Use a CSS background, an <img class="parallax-media" alt="">, or a video inside the media layer. Keep meaningful imagery and interactive video controls outside this decorative pattern. Scroll-driven animation works in supporting browsers; elsewhere the media stays in place. Reduced-motion preferences keep the layer still. No JavaScript or fixed background attachment is needed.

<section class="parallax strong gentle">
  <div class="parallax-media" style="background-image: url('poster.jpg'); background-size: cover; background-position: center" aria-hidden="true">
    <video autoplay muted loop playsinline poster="poster.jpg">
      <source src="background.webm" type="video/webm">
    </video>
  </div>
  <div class="parallax-content"><h2>Your heading</h2></div>
</section>

The video example is decorative and uses a still background when reduced motion is requested. CSS can hide the video visually but cannot reliably stop an autoplaying video from playing or downloading. If playback must stop for reduced-motion users, use user-initiated playback or add optional JavaScript outside Core.
