Build with the native web.

Accessible, adaptable UI built with HTML and CSS. Core needs no JavaScript or build step.

Get startedExplore componentsAPI reference

Start in three steps

1. Add the stylesheet

Download the built CSS from this site, or install @reeris/core when published.

<link rel="stylesheet" href="reeris.css">
2. Use semantic HTML

Keep native controls and add Reeris classes where you need them.

<button class="btn primary">Continue</button>
3. Explore examples

Open a component page for patterns and accessibility guidance.
