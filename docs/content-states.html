Accessibility contract

The visual modifier does not automatically assign a live-region role. Static empty/no-results/permission/maintenance content normally needs no announcement.

When a state appears dynamically, applications choose semantics that match urgency: role="status" for polite updates and role="alert" only for urgent errors requiring immediate announcement.

Meaning is carried by heading/body text and actions, not color or the icon alone. Decorative state icons should use aria-hidden="true".
