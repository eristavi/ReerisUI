Foundation / typography

Words need a clear hierarchy.

Reeris uses the system font by default, a seven-step heading scale, readable body copy, and semantic text roles. Everything is CSS and works without loading a font or running JavaScript.

Heading scale

Use the correct HTML heading level for the document structure. The matching .type-h1 through .type-h6 classes are visual roles when a different size is needed. .type-display is an optional hero treatment, not a heading level.

Public typography tokens

The roles resolve through themeable --reeris-type-* aliases. The size scale, font families, weights, and line heights remain public tokens. Large headings respond to available container width; text remains in rem so browser text sizing still works.
